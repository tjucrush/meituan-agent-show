# 拍照即上线 · Meituan Agent Showcase

美团外卖商家版多模态 Agent 的项目展示网站。

**[打开在线展示 →](https://tjucrush.github.io/meituan-agent-show/)**

从菜品图像到商品草稿，用一页网站展示菜品标准化、商圈查价、推荐定价和营销文案生成的业务流程。

## 页面内容

- 项目概览：场景、痛点与核心能力。
- 实拍场景：三组真实菜品摄影与 28 秒炒锅烹饪视频。
- 交互演示：三组预设菜品、分步流程播放、商品信息复制。
- 实现思路：数据筛选、SFT 任务适配、DAPO 文案优化。
- 项目结果：展示任务成功率、格式正确率、上单耗时和离线 CTR 变化。

本站仅包含 HTML、CSS、JavaScript 与真实菜品摄影、餐饮场景视频。没有算法实现、训练脚本、推理服务、模型权重或真实商家接口。演示使用预设示例，未发布任何实际商品，也不复现项目指标。

## 本地查看

直接打开 `index.html`，或在仓库目录运行：

```bash
python -m http.server 8786
```

访问 `http://localhost:8786`。复制按钮需要浏览器支持剪贴板权限，建议使用 localhost 或 HTTPS。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 单页展示内容 |
| `style.css` | 黄色主题、响应式样式和动效 |
| `script.js` | 预设演示、导航、复制与图表动效 |
| `assets/` | 真实照片、网页视频和站点图标 |

通过 GitHub Pages 从 `main` 分支根目录发布，无构建依赖。

## 数据口径

SFT 后任务成功率 95%+、工具调用 JSON 格式正确率 99.7%、上单耗时 10 秒级；DAPO 文案的离线预估 CTR 相比 SFT 提升 9 BP（0.09 个百分点）。CTR 提升基于推荐侧模型的离线预估，以 SFT 文案为对照。

这是多模态 Agent 项目展示页面，非美团官方网站。
