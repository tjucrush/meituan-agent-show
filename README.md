# 一键上菜 · 餐饮商品录入流程

围绕餐饮商家的商品录入场景，体验从菜品照片与补充信息，到商品资料整理和草稿确认的页面流程。

**[打开网页体验 →](https://tjucrush.github.io/meituan-agent-show/)**

页面可切换不同菜品，查看菜名、口味、规格、价格与商品介绍，并复制整理后的商品资料。交互内容由预设菜品信息驱动，页面不连接商家平台。

## 页面内容

- 流程概览：菜品信息整理、商品内容补全和草稿准备。
- 餐饮场景：菜品摄影与烹饪片段。
- 一键上菜：切换菜品，逐步查看商品资料，并复制内容。

## 本地查看

直接打开 `index.html`，或在仓库目录运行：

```bash
python -m http.server 8786
```

访问 `http://localhost:8786`。复制按钮需要浏览器支持剪贴板权限，建议使用 localhost 或 HTTPS。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 单页上菜流程与交互内容 |
| `style.css` | 页面样式、响应式布局和动效 |
| `script.js` | 菜品预设内容、流程交互、导航与复制 |
| `assets/` | 菜品摄影、餐饮场景视频和站点图标 |

通过 GitHub Pages 从 `main` 分支根目录发布，无构建依赖。
