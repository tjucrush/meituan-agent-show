# 拍照即上线 · Meituan Agent Showcase

美团外卖商家版多模态 Agent 的个人实习项目展示网站。

**[打开在线展示 →](https://tjucrush.github.io/meituan-agent-show/)**

从菜品图像到商品草稿，用一页网站展示菜品标准化、商圈查价、推荐定价和营销文案生成的业务流程。

## 页面内容

- 项目概览：场景、痛点与核心能力。
- 交互演示：三组预设菜品、分步流程播放、商品信息复制。
- 实现思路：数据筛选、SFT 任务适配、DAPO 文案优化。
- 项目结果：按简历口径展示任务成功率、格式正确率、上单耗时和离线 CTR 变化。

本站仅包含 HTML、CSS、JavaScript 与原创 SVG 插画。没有算法实现、训练脚本、推理服务、模型权重或真实商家接口。演示使用预设示例，未发布任何实际商品，也不复现项目指标。

## 本地查看

直接打开 `index.html`，或在仓库目录运行：

```bash
python -m http.server 8786
```

访问 `http://localhost:8786`。复制按钮需要浏览器支持剪贴板权限，建议使用 localhost 或 HTTPS。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 单页展示内容 |
| `style.css` | 黄色主题、响应式样式和动效 |
| `script.js` | 预设演示、导航、复制与图表动效 |
| `assets/` | 原创 SVG 菜品示意和站点图标 |

通过 GitHub Pages 从 `main` 分支根目录发布，无构建依赖。

## 数据口径

项目指标整理自作者提供的简历：SFT 后任务成功率 95%+、工具调用 JSON 格式正确率 99.7%、上单耗时 10 秒级；DAPO 文案的离线预估 CTR 相比 SFT 提升 9 BP（0.09 个百分点）。CTR 指标不是线上 A/B 实验收益；未提供测试集规模及详细评测协议。

这是个人项目展示页面，非美团官方网站。原始简历及联系方式不包含在仓库中。
